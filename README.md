# 🧮 Calculadora Py Tkinter

Calculadora gráfica desenvolvida em **Python** utilizando a biblioteca **Tkinter**.

Este projeto foi desenvolvido como forma de praticar conceitos de Python e desenvolvimento de interfaces gráficas.

## 🚀 Funcionalidades

* Operações de adição (`+`)
* Operações de subtração (`-`)
* Operações de multiplicação (`*`)
* Operações de divisão (`/`)
* Números decimais
* Botão para limpar a tela (`C`)
* Botão para apagar o último caractere (`⌫`)
* Exibição do resultado no visor

## 🛠️ Tecnologias utilizadas

* Python 3
* Tkinter
* Git
* GitHub

## 📂 Estrutura do projeto

```text
calculadora_py_tkinter/
```

## ▶️ Como executar

1. Tenha o **Python 3** instalado.
2. Clone este repositório.
3. Abra a pasta do projeto.
4. Execute:

```bash
python main.py
```

## 📌 Objetivo

O objetivo deste projeto é praticar **Python**, **funções**, **eventos**, **manipulação de strings** e criação de interfaces gráficas utilizando Tkinter.
